# Задание 1

Пусть пользователь из экрана деталей товара захочет перейти в корзину, затем продолжить скроллить
ленту и откроет список товаров. Таким образом стек возврата будет накапливаться, что рано или поздно
приведет к его переполнению.

Из условия движения по графу невозможно из деталей товара в корзину. Поведение расходится с
юзкейсами.

Если пользователь после скролла ленты в списке товаров открывает детали товара, затем корзину, а
затем снова список товаров, то возникает вопрос: "Должна ли лента быть на той же позиции или быть
сначала?".

# Задание 2

- **Top-level экраны**
    - Каталог (стартовый экран), Избранное, Корзина и Профиль.
    - Для каждой такой вкладки организуем собственный независимый граф с поддержкой Multiple Back
      Stacks (saveState = true, restoreState = true, launchSingleTop = true).
- **Сквозной экран** - Детали товара
    - Открывается из Каталога, Избранного и Корзины.
    - Переход делаем с типизированным аргументом (productId).
    - В BackStack возвращаем на исходную страницу, откуда был открыт.
- **Изолированный сценарий** - Оформление заказа
    - Открывается только из корзины.
    - Может быть полноэкранным (Без Bottom Bar, чтобы увеличить конверсию).
    - После оформления очищаем корзину и бэкстек, чтобы пользователь вернулся на каталог или
      профиль, если есть "Мои заказы".

   графического конвейера Compose
